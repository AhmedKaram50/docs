## What is mab-api?

`mab-api` is the backend for the **Mobile-App-Builder** product. It is a standalone API (not a monorepo) shaped as a **DDD modular monolith**:

- **Fastify 5** for HTTP with TypeBox schemas for request/response validation
- **Drizzle ORM** on Postgres 16 for persistence
- **JWT access tokens** (short-lived) + **opaque refresh tokens** (long-lived, hashed in DB)
- One folder per bounded context under `src/modules/`

Each module follows the same four-layer shape:

```
domain/ → application/ → infrastructure/ → interfaces/
```

## Start here

<Steps>
  <Step title="Install">
    Clone the repo, run `npm install`, copy `.env.example` → `.env`, see [Installation](/getting-started/installation).
  </Step>
  <Step title="Configure">
    Provide DB, JWT secret, Shopify keys — see [Environment](/getting-started/environment).
  </Step>
  <Step title="Boot">
    `npm run db:fresh` then `npm run dev` — see [Running locally](/getting-started/running-locally).
  </Step>
  <Step title="Call the API">
    Start with [Identity → Auth](/modules/identity/auth) for register/login/refresh.
  </Step>
</Steps>
